# 🎬 Manimations Repository

Welcome to **Manimations** — a curated collection of animations created using **[Manim](https://www.manim.community/)**, the mathematical animation engine.

This repository serves as a central place for all my Manim projects, experiments, and visual explanations.

---

## 📦 What’s Inside

- 📐 Mathematical animations  
- 📊 Visual explanations of concepts  
- 🎨 Creative & experimental Manim scenes  
- 🧪 Practice and demo projects  

Each folder or file represents a standalone Manim animation or a small related set of scenes.

---

## 🚀 Usage

All animations in this repository are **free to use**.

You are welcome to:
- ✔️ Use them in your own projects
- ✔️ Modify and adapt them
- ✔️ Share them with others
- ✔️ Use them for learning, teaching, or presentations

No permission is required — just enjoy and create.
